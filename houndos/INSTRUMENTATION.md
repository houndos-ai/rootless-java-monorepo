# Instrumentation

Generated by HoundOS. This directory documents the OpenTelemetry instrumentation HoundOS added to this repository.

- `houndos.yaml` (repo root) — the agreed SLO contract, the source of truth.
- `houndos/services/<service>.md` — what a service's instrumentation records, how it is set up, and what to check when reviewing it. One file per service, changed only by that service's PRs.
- `houndos/instrumentation/<service>/` — sample code for a service HoundOS could not edit automatically. Not compiled; copy what you need.
- `houndos/legacy/` — notes written before this layout (November 2026). A service's next PR replaces its note with `houndos/services/<service>.md`.
